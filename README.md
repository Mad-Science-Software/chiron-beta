# Chiron beta

Chiron gives your Claude a long-term memory. It remembers what you've told it and
worked on together, across sessions and projects, and brings related memories to mind
as you type.

Everything runs on your own computer. Your memories never leave it, and Mad Science
Software never sees them.

## Installing

You don't need to do this by hand. Open Claude Code and say:

> Install Chiron by following https://github.com/Mad-Science-Software/chiron-beta/blob/main/docs/setup.md

It takes about 15 minutes. You'll need:

- a Mac with about 3 GB of free disk space (Windows support is being tested),
- [Claude Code](https://claude.com/claude-code),
- Docker Desktop (Claude will help you install it if you don't have it).

Before installing, read [BETA.md](BETA.md): it's short, and it explains what taking part
means.

## Feedback

This is a beta, so things will break. Please email anything that goes wrong, feels off
or surprises you to **james@madsciencesoftware.dev**. Screenshots or a copy of what
Claude said help a lot. Never send your memories themselves.
