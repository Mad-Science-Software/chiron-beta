# Saving to Chiron memory

Memories are permanent: nothing can be edited or deleted, only superseded by a newer
memory. Save only what the user would be comfortable keeping, and ask before saving
anything personal about them or other people.

1. **Pick what's worth keeping.** Decisions and their reasons, changes of mind, lessons
   from something that went wrong, facts about people and projects the user will want
   later. Skip routine steps and anything already obvious from the code or files.
2. **Check it isn't already stored.** `recall` with the topic's own terms. If an older
   memory says something different, save the new one anyway: the later date is what
   supersedes it.
3. **Save it with `preserve`.** Follow the cue-writing rules in the tool's description.
   Credit the people and AI models who said or decided it, by name, with the date it
   happened (not today, if it was earlier). Never save passwords, keys or other
   credentials.
4. **Tell the user** in a line what you saved.

To correct a memory, save a new one stating the correction; the old one stays as the
record of what was said then.
